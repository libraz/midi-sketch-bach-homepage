# 4. 旋律の書法

縦の関係が合法でも、曲を台無しにする音はあります。対位法は、どの声部も単独で読んだときに妥当な旋律——歴史的には*歌える*旋律——であることを要求します。そのため検証器は声部間の縦の音程だけでなく、各声部の内部の旋律音程も検査します。

::: info 縦の音程と旋律音程
**縦の音程**は、同じ瞬間の二つの声部を比べます。**旋律音程**は、一つの声部の今の音と次の音を比べます。検証器は両方の次元を見ます。この章はその後者です。
:::

## 禁止される跳躍

エンジンは、生成される旋律線の直接進行について、増音程・減音程・三全音という三つの音程カテゴリーを保守的に禁じます。歴史上の扱いは、音程の綴り、調性上の文脈、音楽的な設定によって変わります。

::: info 増と減をひとことで
**増音程**は完全または長音程より半音広い音程です。**減音程**は、完全音程なら完全音程より半音狭く、長短音程なら短音程より半音狭い音程です（[凡例](/ja/docs/music-primer#音程の名前と種別)）。増2度は3半音で、12平均律では短3度と同じ半音数になりますが、音名の綴りと調性上の文脈が書かれた音程名と扱いを決めます。
:::

<CounterpointStaff example="augmentedSecond" locale="ja" />

増2度は短調で自然に発生するため、専用の譜例に値します。和声的短音階は第7音（導音）を半音上げるので、自然な第6音とのあいだに3半音の溝が残ります。ただし歴史上の調性音楽では、音度の変化は和声と声部進行に従い、上行・下行のどちらでも第6・第7音が上がることがあります。上行・下行の旋律的短音階というおなじみの型は、便利な学習モデルであって、バッハが機械的に適用した規則ではありません。MIDI Sketch Bach では形式ビルダーがこの音程検査のためのキャリア素材を選び、禁止跳躍が最終スコアに入れば検証器が退けます。[一般的な調性音楽の音階の概要](https://open.lib.umn.edu/musiccomposition/chapter/common-practice-era-scales-intervals-and-chord-functions/)も参照してください。

::: info 短音階の三つの形
短調の和音語彙は一つですが、音階について三つの便利な教科書的綴りがあります。**自然短音階**（変化なし）、**和声的短音階**（第7音を半音上げて導音を作る）、**旋律的短音階**（一般には上行で第6音*と*第7音を上げ、下行で自然形に戻すと説明されます）。これらは三つの排他的な音階ではありません。バッハを含む作曲家は、和声や声部進行に応じて上行・下行のどちらでも第6・第7音を変化させます。和声的短音階の上がった第7音は第6音とのあいだに増2度の間隔を開き、旋律的短音階はその間隔を避ける一つの方法です。
:::

この迂回は理論上の抽象ではありません——無伴奏チェロ組曲第5番の、第1小節そのものです。

::: tip 借用和音による免除
宣言された副次ドミナント圏の内側では、半音階的な動きこそが*目的*です。そのため `augmented_melodic`・`diminished_melodic`・`tritone_melodic` はいずれもそこでは免除されます。借りてきた導音は、導音として振る舞うことを許されるのです。
:::

::: info 減7度はどこに？
MIDI は半音数を記録しますが、音名の綴りは保持しません。12平均律では異なる綴りが同じ半音数になることがあるため、半音数だけで固有の音程名や歴史的な扱いは決まりません。減7度（9半音——イ短調の G♯ から上の F）は、このデータ上では長6度と区別できないため、`diminished_melodic` はその綴りを検出できず、検出もしません。検証器は旋律ルール上、6半音と11半音の幅を保守的に分類します。これらも半音数だけでは綴りが一意にならず、半音階的な文脈によって音楽的な解釈が変わり得ます。3半音の A2/m3 については、エンジンが調から復元し、両端が*隣り合う音度*にある場合に検出します。スケール外の音に触れる3半音の跳躍も保守的に検出します。副次ドミナント圏では、これらの旋律ルールは免除されます。
:::

その適用範囲が開けたままにしている空間を、バッハが見せてくれます。嬰ハ短調フーガの主唱は*綴りの上では*減4度——半音数では4で、12平均律では長3度と同じ半音数——を跳躍し、このルールが本当に問題にしている「扱い方」の手本を示します。

## 跳躍には回復が要る

協和音程への跳躍であっても無制限ではありません。**順次進行**は隣のスケール音への移動、それより大きい動きはすべて**跳躍**です（[入門](/ja/docs/music-primer#順次進行と跳躍)）。跳躍は旋律のエネルギーを消費し、逆方向の順次進行がそれを返済します。大きな跳躍が二つ続いて回復がないと、その線は声部として聞こえなくなります。

## 輪郭——フレーズに頂点は一つ

<CounterpointStaff example="melodicArch" locale="ja" />

このアーチを直接強制する単一のルールはありません。既定の経路では、形式ビルダーが書いた旋律をキャリアが再生するため、輪郭もその素材から生まれます。採点探索が既定の旋律形を作るわけではなく、使えるのはオプトインのパッサカリア対旋律だけです。それでも、生成された声部を読むときにアーチを知っておく価値はあります。一つの頂点へ上り、そこから収まる線は、まとまったフレーズに聞こえます。

バッハの「小フーガ」ト短調（BWV 578）の冒頭主唱は、早い段階で高点に達してから開始時の音域へ戻る、コンパクトなアーチを示します。

## 導音の義務

[第7音度](/ja/docs/music-primer#音度-スケール・ディグリー)——主音の半音下——は**導音**と呼ばれます。導く音、という意味です。ドミナントの文脈でこの音が鳴った瞬間、聴き手は次に主音を期待します。素材はある音を導音として印づけることができ、検証器はその約束を声部に守らせます。

<CounterpointStaff example="leadingTone" locale="ja" />

## 音域の整合性

各声部はテクスチュアプランの中で演奏可能な音域も宣言します（ソプラノ・アルト・テノール・バス、オルガンなら手鍵盤とペダルの音域）。宣言された MIDI 範囲の外に出た音は `voice_range_integrity` で失敗します。これは様式の規則というより物理の規則で、[楽器](/ja/docs/physical-models)に記載した楽器ごとの音域と対になっています。

## 検証器はこの章をどう見るか

| ルール | FailKind | 検査内容 |
|--------|----------|----------|
| `augmented_melodic` | MusicalFail | 6半音の跳躍と、両端が隣接する音度に乗る——またはスケール外の音を含む——3半音の跳躍（増2度。綴りは調から復元）を検出。副次ドミナント圏では免除。 |
| `diminished_melodic` | MusicalFail | 6半音と11半音の旋律的な幅を保守的に検出（綴りとしては A4/減5度、長7度/減8度など）。9半音の減7度/長6度は MIDI 上で区別できないため検出されない。副次ドミナント圏では免除。 |
| `tritone_melodic` | MusicalFail | 6半音の直接跳躍を禁止。同上の免除。 |
| `consecutive_leaps` | MusicalFail | 大跳躍（5度以上）を2回連続させない（方向は問わない）。終止セルの音は免除。 |
| `leading_tone_resolution` | MusicalFail | 導音として印づけられた音は、同じ声部の次の音で主音のピッチクラスへ順次上行する。 |
| `voice_range_integrity` | MusicalFail | すべての音が、その声部が宣言した MIDI 範囲 `[lo, hi]` に収まる。 |
