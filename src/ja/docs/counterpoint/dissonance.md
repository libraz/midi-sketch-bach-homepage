# 3. 不協和音の扱い

不協和音そのものは禁止ではありません。対位法はむしろ、不協和音が生み出し解決する緊張で駆動します。検証器が退けるのは*管理されていない*不協和です。この章では合法的な型を、不協和を置ける場所を決める拍節の規則から、不協和を意図的に演出する掛留まで、順にカタログ化します。

エンジンは三つの問いを区別します。

1. その縦の音程は不協和か？（第1章の分類）
2. その音は、構造的に強い位置で和声音か？
3. 安定でないなら、準備と解決はあるか？

::: info 和声音と非和声音
**和声音**は、その場の和音に属する音です。ハ長調の主和音なら C・E・G が和声音です。D や F も音楽的でありえますが、安定音のあいだを順次でつなぐ「経過」のような機能が必要になります。これが**非和声音**（NCT）です。
:::

## 構造的アクセントは和声音を要求する

小節頭は常に構造の支点です。拍子はさらに中強の支点を加えます。4/4 の3拍目、複合拍子の付点拍、サラバンドの2拍目、より長い偶数単純拍子の中央です（[入門](/ja/docs/music-primer#強拍と弱拍)）。エンジンは、すべての構造的アクセントに置かれる生成音がその場の**和音**——和音の根音・第3音・第5音と、和音が7度を宣言している場合の第7音（[入門](/ja/docs/music-primer#和音と和声)）——に属すること、そしてそこで同時に鳴る声部ペアが実際のバスに対して協和することを要求します。

<CounterpointStaff example="verticalDissonance" locale="ja" />

| ルール | 発火条件 |
|--------|----------|
| `strong_beat_dissonance` | Compose 由来の音が構造的アクセントにあり、その時点の和音の構成音ではない。和音が7度を持つときは第7音も含む。 |
| `vertical_dissonance` | 構造的アクセントで同時に鳴る声部ペアが不協和。基本の協和集合は `{0, 3, 4, 5, 7, 8, 9}` だが、実際のバス上の4度は、宣言された掛留または終止6/4がない限り不協和。上声部間の4度は合法になりうる。固定出自の扱いは `Generation`/`FinalScore` のライフサイクルと形式の垂直予算に従う。 |

第7音の扱いは意図的に分かれています。強い位置では、現在の和音が宣言した第7音は和声音です。弱い位置の非和声音検査では三和音の根音・第3音・第5音だけを使うため、和音上の第7音をそこで非和声音として扱う場合は、適切な順次進行による準備と解決が必要です。

## 弱い位置は「読める」不協和を許す

構造的アクセントと次のアクセントのあいだでは、旋律線が機能を聴き取らせる限り——つまり[順次進行](/ja/docs/music-primer#順次進行と跳躍)（隣のスケール音への移動、2半音以内）で入って順次で出る限り——不協和な非和声音が許されます。古典的な型は二つです。

<CounterpointStaff example="passingTone" locale="ja" />

<CounterpointStaff example="neighborTone" locale="ja" />

**経過音**は、3度離れた二つの和声音のすき間を順次で埋めます。**刺繍音**は、和声音から一歩離れてすぐ戻ります。どちらも安定した枠の装飾として聞こえます。

バッハはこの型を16分音符の速度で実行します。ハ長調フーガ（平均律 I 巻）の第2小節では、走る線が上の応唱と2度衝突します——4度、つづいて7度。そしてどちらの衝突も契約を満たしています。

<CounterpointStaff example="bachPassingTones" locale="ja" />

同じ不協和でも、その枠がなければ失敗します。

<CounterpointStaff example="unpreparedDissonance" locale="ja" />

| ルール | 発火条件 |
|--------|----------|
| `unprepared_dissonance` | `Generation` では、弱い位置の非和声音への接近または離脱が2半音を超える——経過音でも刺繍音でもない。`FinalScore` では全出自を監査します。声部の最初と最後の音は免除——片側に隣の音が存在せず、「順次で入ったか」を評価しようがないからです。 |

## 掛留——予約された不協和

掛留は調性音楽で最も意図的な不協和です。三段階の型で、エンジンの素材モデルはこれを明示的に宣言します。

::: info 掛留をひとことで
安全だった音が**保持**され、その下で和声が変わって一時的な緊張が生まれ、順次進行で解決する。遅延した更新と考えてください。古い値が1拍だけ残り、それから追いつくのです。
:::

1. **準備** — その音が協和音程として鳴る。
2. **掛留** — 相手声部が動くあいだ、その音が**タイ**（同じ高さの音を弧線でつなぎ、境界をまたいで一つの音として鳴らし続ける記法）で保持され、宣言された不協和が生まれる。
3. **解決** — 保持されていた声部が、定められた方向へ全音階の一歩だけ動く。

エンジンは4種類の宣言パターンを検証します。4-3、7-6、9-8は一般的な掛留の名称に対応しますが、`2-3` は歴史的な下声部の2-3掛留で通常用いられる方向ではなく、エンジン固有の方向契約です。歴史的な下行解決については[Open Music Theory](https://viva.pressbooks.pub/openmusictheorycopy/chapter/fourth-species-counterpoint/)も参照してください。名前は「バス上の不協和音程→解決後の音程」を示します。

連鎖させると、掛留は単発の出来事ではなくテクスチュアになります。各解決音が、そのまま次の準備音を兼ねるのです。

バッハが平均律 I 巻を閉じるロ短調プレリュードは、まさにこのテクスチュアで幕を開けます——ただし掛留は、歩くバスの上で二つの声部のあいだを行き来します。

<CounterpointStaff example="bachSuspensionChain" locale="ja" />

| 型 | 不協和 → 解決 | 方向 | よく現れる場所 |
|----|----------------|------|----------------|
| 4-3 | バス上の4度 → 3度 | 下行 | 終止 |
| 7-6 | 7度 → 6度 | 下行 | ゼクエンツの連鎖（いわゆる 7-6 連鎖） |
| 9-8 | 9度 → オクターヴ | 下行 | 落ち着く場面。完全音程への解決なので収束感が強い |
| 2-3 | 2度（バスの掛留）→ 3度 | **このエンジンでは上行** | エンジンのバス掛留キャリア。歴史的な下声部の2-3掛留は、バスが下行して通常は下行解決する |

## 検証器はこの章をどう見るか

| ルール | FailKind | 検査内容 |
|--------|----------|----------|
| `strong_beat_dissonance` | MusicalFail | `Generation` では、構造的アクセントの Compose 由来ピッチクラスがその場の和音に属する。和音が宣言した第7音も含む。`FinalScore` では全出自を監査します。 |
| `vertical_dissonance` | MusicalFail | 構造的アクセントの同時音程がバス基準で協和するか、有効な掛留・終止6/4の許可を持つ。出自の扱いは `FinalScore` と形式の予算まで続きます。 |
| `unprepared_dissonance` | MusicalFail | 弱い位置の非和声音は順次（2半音以内）で出入りする。 |
| `suspension_preparation` | MusicalFail | 準備音が最低声部に対して協和で、同じ音高のまま掛留へタイでつながる。 |
| `suspension_preparation_duration` | MusicalFail | 準備音は、それが準備する掛留以上の長さを持つ。 |
| `suspension_metrical_accent` | MusicalFail | 掛留は準備音より強い拍位置に置く。 |
| `suspension_resolution_step_down` | MusicalFail | 解決は 1〜2 半音の一歩。方向は型ごとに固定——4-3 / 7-6 / 9-8 は下行、2-3 は上行。 |
| `suspension_interval` | MusicalFail | 掛留声部と同時に鳴る他声部の最低音との音程が、宣言された型（4-3 / 7-6 / 9-8 / 2-3）に一致する。2-3 では掛留声部がバスなので、そこから上向きに測定します。 |
| `suspension_seventh_sixth` | MusicalFail | 宣言された 7-6 型が、最低声部の上に本物の7度を作り、本物の6度へ解決する（プロビナンスビットで確認するため、掛留キャリアが実際に出荷されていない場面では不発）。 |
