# プリセット一覧

MIDI Sketch Bach のすべての設定可能なプリセットの一覧です。

::: info 表の読み方
`ID` と `文字列` はAPIで使う値です。声部数、拍子、スナップ前の基準小節数、調、性格は音楽構造に関する選択です。用語が曖昧な場合は、[エンジニアのための音楽用語入門](/ja/docs/music-primer)を開いたまま読むと追いやすくなります。
:::

## 楽曲形式一覧

### 全10形式

| ID | 名前 | 文字列 | カテゴリ | 既定楽器 | 声部数 | 拍子 | スナップ前の基準小節数 | `short` 出力小節数 |
|----|------|--------|---------|----------|--------|------|----------------------|------------------|
| 0 | フーガ | `"fugue"` | オルガン | オルガン | 3 | 4/4 | 42 | 44 |

| 3 | コラール前奏曲 | `"chorale_prelude"` | オルガン | オルガン | 3 | 4/4 | 16 | 16 |

| 9 | ゴルトベルク変奏曲 | `"goldberg_variations"` | 変奏 | チェンバロ | 3 | 4/4 | 20 | 20 |

::: info 小節数について
「スナップ前の基準小節数」は形式が持つ元の長さです。`scale` がこの値を倍率で伸ばし（約1倍/2倍/3倍/4倍）、形式ごとの小節単位へスナップします。そのため、フーガの基準値は42小節ですが、`scale: "short"` の出力は44小節です。`targetBars: 0` は `scale` を使い、正の `targetBars` はこれを上書きします。範囲とスナップの注意点は[オプション関係](/ja/docs/option-relationships)を参照してください。ゴルトベルクの `scale: "full"` は 20 × 4 = 80 小節ではなく、完全な 128 小節のレイアウトを選びます。
:::

::: tip 基準小節数は秒数ではありません
小節数は音楽上の長さであり、実時間ではありません。再生時間は `bpm` と拍子にも依存します。80 BPM の44小節フーガは、140 BPM の同じ44小節より長く再生されます。
:::

### 楽曲形式選択フローチャート

![まず楽器を選ぶ。オルガンには 7 形式、独奏チェロ・独奏ヴァイオリン・チェンバロにはそれぞれ 1 形式が開き、シャコンヌは 3 つの宣言声部を持つ](/images/form-selection-ja.svg)

::: info オルガン系（形式 0--6）
7つのオルガン形式はバッハのオルガン・レパートリーの主要ジャンルをカバーします。すべて既定の `organ` 音色を使い、3声部を使用します。
:::

::: info 独奏楽器系（形式 7--8）
2つの独奏形式は無伴奏弦楽器のための音楽を生成します。チェロ前奏曲は単一の連続線です。シャコンヌのプリセットは 3 つのレーンを宣言します。V0 は変奏、V1 は他声部と衝突しない音域があるときに中声を加え、V2 は低音域のグラウンドを担います。V1 は冒頭では休み、適切な配置がない小節や周期では休符になります。歴史上のシャコンヌやパッサカリアでは、オスティナートを移動・変奏・装飾し、音高と音価を同一のまま反復しない場合があります。プリセットの不変キャリアはエンジンの制約です。歴史上の呼称が重なり合うことについては、[SFCM のオスティナート形式の解説](https://sfcm.edu/study/majors/academics/music-theory-and-musicianship/sfcm-theory/online-materials/analysis-lectures/ostinato-and-variation)を参照してください。
:::

::: info 変奏系（形式 9）
ゴルトベルク変奏曲形式は、エンジンのキャリアとして不変のバス音符列を使い、既定はチェンバロです。`scale: "full"` で正の `targetBars` を指定しない場合は、20 × 4 = 80 小節ではなく、完全な圧縮レイアウトである 128 小節を選びます。正の `targetBars` は `scale` を上書きします。歴史上の変奏が保つのはアリアの基礎低音と和声の構想であり、実際に鳴るバスの音高や音価は変わり得ます。API の音符単位の不変性は、これより厳しい実装上の制約です。[オランダ・バッハ協会の BWV 988 解説](https://www.bachvereniging.nl/en/bwv/bwv-988)と、[オックスフォード書誌のオスティナート変奏に関する解説](https://academic.oup.com/reference/62400/reference-article-abstract/555408310)を参照してください。
:::

::: details 形式別BWV 参照
| 形式 | バッハの代表作 |
|------|--------------|
| フーガ | BWV 578（ト短調「小フーガ」）、BWV 542/2 |
| 前奏曲とフーガ | BWV 532, 541, 548, 846--893（平均律クラヴィーア曲集） |
| トリオ・ソナタ | BWV 525--530（6つのトリオ・ソナタ） |
| コラール前奏曲 | BWV 599--644（オルゲルビュッヒライン）、BWV 651--668 |
| トッカータとフーガ | [BWV 565（ニ短調、伝統的な帰属だが作者は議論中）](https://www.bachvereniging.nl/en/bwv/bwv-565)、BWV 540 |
| パッサカリア | BWV 582（ハ短調） |
| 幻想曲とフーガ | BWV 537, 542 |
| チェロ前奏曲 | BWV 1007--1012（無伴奏チェロ組曲） |
| シャコンヌ | BWV 1004/5（パルティータ第2番ニ短調） |
| ゴルトベルク変奏曲 | BWV 988 |
:::

## 楽器一覧

| ID | 名前 | 文字列 | GMプログラム | 音色 | 受け付ける形式 |
|----|------|--------|-----------|---------|----------------|
| 0 | オルガン | `"organ"` | 19 | チャーチオルガン | オルガン形式（0--6） |
| 1 | チェンバロ | `"harpsichord"` | 6 | チェンバロ | ゴルトベルク変奏曲（9） |
| 2 | ピアノ | `"piano"` | 0 | アコースティックグランドピアノ | ゴルトベルク変奏曲（9） |
| 3 | ヴァイオリン | `"violin"` | 40 | ヴァイオリン | シャコンヌ（8） |
| 4 | チェロ | `"cello"` | 42 | チェロ | チェロ前奏曲（7） |
| 5 | ギター | `"guitar"` | 24 | ナイロンギター | -- |

::: info 楽器は作曲構造を決めません
`instrument` はMIDI 音色、演奏可能音域、装飾密度を選びます。声部数、拍子、形式レイアウト、検証器ルールは変えません。それらは `form` から決まります。
:::

::: warning 楽器は形式が固定する
ゴルトベルク変奏曲を除くすべての形式は、その形式が書かれた楽器 1 つだけを受け付けます。別の楽器を指定しても移し替えは行われず、楽器非互換エラーになります。選択肢があるのはゴルトベルク変奏曲だけで、`harpsichord` と `piano` から選べます。
:::

## 主題の性格

| ID | 名前 | 文字列 | 効果 |
|----|------|--------|------|
| 0 | Severe | `"severe"` | 厳格で知的に緻密（既定） |
| 1 | Playful | `"playful"` | 軽快で機敏、リズミカル |
| 2 | Noble | `"noble"` | 荘重で広やか、威厳のある |
| 3 | Restless | `"restless"` | 推進力があり半音階的で劇的 |

::: info
`character` パラメータはフーガ主題や主要な主題素材の旋律傾向に影響します。フーガ系形式で最も顕著な効果があり、主題が楽曲全体の性格を定義します。さらに、すべての形式で音符のアーティキュレーションと MIDI CC プロファイルも変わります。`cello_prelude` では、小節ごとに使う音型パレットの順序も変わります。楽器ごとの表現出力は[楽器](/ja/docs/physical-models)を参照してください。2つの組み合わせは禁止されており例外を投げます。`chorale_prelude` は `playful`/`restless` を、`toccata_and_fugue` は `noble` を拒否します。
:::

## スケールモード

`scale` は形式の基準長を倍率で伸ばします。`targetBars: 0` は `scale` を使い、正の `targetBars` がこれを上書きします。ゴルトベルクの `scale: "full"` は、正の `targetBars` を指定しない場合に完全な圧縮 128 小節レイアウトを選びます。

| ID | 名前 | 文字列 | おおよその長さ |
|----|------|--------|-------------|
| 0 | Short | `"short"` | 基準長の約1倍（既定） |
| 1 | Medium | `"medium"` | 基準長の約2倍 |
| 2 | Long | `"long"` | 基準長の約3倍 |
| 3 | Full | `"full"` | 基準長の約4倍。ゴルトベルクは完全な 128 小節レイアウト |

::: tip
実際の出力長は各形式の基準長に依存します（上記の楽曲形式一覧表を参照）。各形式は自身の基準長を基準に伸縮するため、同じ `scale` でも形式によって小節数は異なります。`targetBars` の範囲、実用的な値、出力の丸め込みについては[オプション関係](/ja/docs/option-relationships)を参照してください。
:::

## 調の一覧

調の表には、API の正規名とピッチクラス ID を示します。`key` には ID と名前のどちらも指定できます。

| ID（ピッチクラス） | API の正規名 |
|------------------|-------------|
| 0 | `"C"` |
| 1 | `"C#"` |
| 2 | `"D"` |
| 3 | `"Eb"` |
| 4 | `"E"` |
| 5 | `"F"` |
| 6 | `"F#"` |
| 7 | `"G"` |
| 8 | `"Ab"` |
| 9 | `"A"` |
| 10 | `"Bb"` |
| 11 | `"B"` |

::: info 調名、綴り、音律
`key` はピッチクラスを選び、`isMinor` は長調か短調かを選びます。例えば `key: 2, isMinor: false` はニ長調、`key: 2, isMinor: true` はニ短調です。API の12個の ID は正規の調名を使い、異名同音の綴り、歴史上の音律、調律を表しません。時代の調性格の記述には相違があり、この表へ単純には対応しません。[調性格に関するマッテゾンの議論](https://revistas.usp.br/revistamusica/en/article/view/55111)と、[1713年資料の米国議会図書館コピー](https://www.loc.gov/item/07013014/)を参照してください。
:::

すべての調で `isMinor: false`（長調）と `isMinor: true`（短調）の両方が使用できます。

## プログラムによるアクセス

実行時にこれらの値にアクセスするにはプリセット列挙関数を使用します。

```js
import {
  init,
  getForms,
  getInstruments,
  getCharacters,
  getDefaultInstrumentForForm,
  getKeys,
  getScales,
  getVersion
} from '@libraz/midi-sketch-bach'

await init()

// すべての形式を一覧
const forms = getForms()
for (const form of forms) {
  console.log(`${form.id}: ${form.display ?? form.name}`)
}
// 0: Fugue
// 1: Prelude and Fugue
// 2: Trio Sonata
// 3: Chorale Prelude
// 4: Toccata and Fugue
// 5: Passacaglia
// 6: Fantasia and Fugue
// 7: Cello Prelude
// 8: Chaconne
// 9: Goldberg Variations

// すべての楽器を一覧
const instruments = getInstruments()
// [{ id: 0, name: "organ" }, ...]

// すべての調を一覧
const keys = getKeys()
// [{ id: 0, name: "C" }, { id: 1, name: "C#" }, ...]

// 形式の既定楽器 ID を取得
const celloPreludeInstrument = getDefaultInstrumentForForm(7)
// 4（チェロ）
```

::: tip
これらの関数はドロップダウンや楽曲形式セレクターなどのUI コンポーネントの構築に便利です。このサイトのデモでは楽曲形式選択インターフェースの入力にこれらを使用しています。
:::

`getDefaultInstrumentForForm(formId: number): number` は楽曲形式 ID 0--9 を受け取ります。無効または範囲外の値には `0`（オルガン）を返します。
